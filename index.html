Omnom Linux

home repo blog about

minimalist. source-based. modern.

Linux distribution built from scratch with LFS, OpenRC, Hyprland and NixOS-style generations.

alpha stage – iso expected nov 2026

package management

  • unified interface: omnom-install
  • auto-detects dnf / pacman / apt / emerge
  • fallback to source compilation
  • our – omnom user repository

system & safety

  • nixos-style generations
  • rollback to any previous state
  • openrc – lightweight init
  • low ram usage (512mb min)

desktop

  • hyprland or niri (wayland)
  • kitty terminal (gpu-accelerated)
  • fish shell with autosuggestions
  • vulkan support recommended

build & deps

  • gcc 12+ / clang 15+
  • python 3.10+, git, cmake, meson
  • kernel 6.0+ with wayland
  • glibc 2.35+ or musl

commands

omnom-install

omnom-install firefox # auto-detect omnom-install firefox --emerge # compile from source omnom-install firefox --our # from our repo omnom-install --list # installed packages omnom-install --search term # search all repos omnom-install --remove pkg # remove package

omnom-upgrade

omnom-upgrade --all # full system update omnom-upgrade firefox # update single pkg omnom-upgrade --check # check updates omnom-upgrade --rollback # rollback generation omnom-upgrade --list-generations omnom-upgrade --switch gen

configuration

# /etc/omnom/omnom.conf DEFAULT_METHOD="auto" GENERATIONS_KEEP=10 CFLAGS="-O2 -march=native -pipe" MAKEOPTS="-j$(nproc)" OUR_REPO_ENABLED=true OUR_REPO_URL="https://frosr1o2.github.io/OmnomOS-Omnom-linux" AUTO_CLEANUP=true
