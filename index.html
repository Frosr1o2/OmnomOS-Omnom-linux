OMNOM LINUX

Minimalist source-based Linux distribution

Requirements

Minimum Hardware

  • CPU: x86_64 or ARM64, 1 GHz or faster
  • RAM: 512 MB minimum (2 GB recommended)
  • Storage: 16 GB minimum (32 GB recommended)
  • Graphics: GPU with Wayland support for Hyprland/Niri and kitty/alacritty

Build Dependencies

  • Compiler: GCC 12+ or Clang 15+
  • Make: GNU Make 4.0+
  • Python: 3.10+ (for build scripts)
  • Git: 2.30+ (for source fetching)
  • CMake: 3.20+ (for some packages)
  • Meson: 1.0+ (for some packages)
  • Ninja: 1.10+ (for fast builds)

Runtime Dependencies

  • Kernel: Linux 6.0+ (with Wayland support)
  • libc: glibc 2.35+ or musl 1.2+
  • OpenRC: 0.45+ (init system)
  • Wayland: 1.22+ (display server)
  • Hyprland: 0.35+ or Niri 0.1+
  • Kitty: 0.30+ (terminal)
  • Fish: 3.6+ (shell)

Package Manager Backends (Optional)

  • DNF: 4.10+ (for RPM packages)
  • Pacman: 6.0+ (for Arch packages)
  • APT: 2.4+ (for Debian packages)
  • Portage: 3.0+ (for Gentoo emerge)
  • Yay/Paru: (for AUR support)

Commands

omnom-install

Intelligent package installer with auto-detection and fallback options.

Installation priority: DNF → Pacman → AUR → OUR → Source compilation.

omnom-install firefox # Auto-detect best method omnom-install firefox --emerge # Force compile from source omnom-install firefox --our # Install from Omnom User Repository omnom-install firefox --dnf # Force use DNF omnom-install firefox --pacman # Force use Pacman omnom-install firefox --aur # Force install from AUR omnom-install --list # List all installed packages omnom-install --search <term> # Search across all repositories omnom-install --remove <package> # Remove installed package

omnom-upgrade

System updater with rollback capabilities.

omnom-upgrade --all # Update everything omnom-upgrade firefox # Update specific package omnom-upgrade our # Update Omnom User Repository omnom-upgrade --check # Check for updates omnom-upgrade --rollback # Rollback to previous generation omnom-upgrade --list-generations # List all system generations omnom-upgrade --switch <generation> # Switch to specific generation

Features

NixOS-Style Generations

  • Every install/upgrade creates a new system generation
  • Easy rollback to any previous state
  • Keep up to 10 generations by default (configurable)

Multi-Backend Support

  • Seamless work with DNF, Pacman, APT, Emerge
  • Unified interface across different package managers
  • Automatic fallback if primary method fails

Omnom User Repository (OUR)

  • Community-driven package repository
  • Simple .pkg format for package definitions
  • Local package creation support

Source Compilation

  • Gentoo-style emerge support
  • Automatic dependency resolution
  • Optimized for specific hardware
  • Custom compiler flags support

File Structure

/etc/omnom/ ├── omnom.conf # Main configuration ├── repos.conf # Repository configuration └── flags.conf # Default compiler flags /var/lib/omnom/ ├── generations/ # All system generations │ ├── gen-20240315_120000/ │ ├── gen-20240315_150000/ │ └── current -> gen-20240315_150000/ ├── packages.list # Currently installed packages └── history.log # Installation/upgrade history ~/.config/omnom/ ├── our-repo/ # Local OUR packages └── omnomrc # User configuration ~/.cache/omnom/ └── builds/ # Temporary build files

Configuration Example

# /etc/omnom/omnom.conf DEFAULT_METHOD="auto" GENERATIONS_KEEP=10 CFLAGS="-O2 -march=native -pipe" MAKEOPTS="-j$(nproc)" OUR_REPO_ENABLED=true OUR_REPO_URL="https://frosr1o2.github.io/OmnomOS-Omnom-linux" AUTO_CLEANUP=true

Benefits

  • Flexibility: Mix and match package managers
  • Safety: Automatic generations with easy rollback
  • Control: Choose between binary or source compilation
  • Simplicity: Single command for all package operations
  • Efficiency: Optimized for low RAM usage
  • Modern: Wayland + Hyprland for smooth desktop experience
